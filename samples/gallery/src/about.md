# What mndflow draws

Every example uses only the base package.

| Folder | What it shows |
|---|---|
| Diagrams | one example per diagram kind, in kind order |
| Registries | types, tags, interfaces and constraints, each with its uses |
| Faces | small and large cards: table, class, document, picture, text |
| Visuals | lines and their ends, ties, ports, groups, grids, regions, labels, notes, colour |
