# packages/flow

Directed relationship subtypes: control flow, object flow and transition.
An object flow may carry an `item` — that is SysML's item flow, a field on
the relationship rather than a fourth subtype. Data only — no module, no
renderer, no layout law.

Loading into a project is A0.3. Until then these files sit ready; nothing
imports them. Behavior vocabulary words (action, state, message) are A.10.
