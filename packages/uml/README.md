# packages/uml

UML reading: structural and use-case definitions, activity ornaments, and
`names` that answer to SysML where the concepts align. Data only — no module,
no renderer, no layout law.

Ornaments match the SysML package — shape plus size on the definition, never a
fifth form. An actor wants a real icon still (tasks.md); the card layout is
`icon` so one can land without a schema change.

Loading into a project is A0.3. Until then these files sit ready; nothing
imports them.
