# Row

**Draft, 2026-10-29: for agreement.** A row is an element listed in the explorer: its place in the tree, said in one line. It is the smallest form after the mark and says what the element's card says.


## Purpose

| Question | How the row answers |
|---|---|
| *where is it?* | its indent under what holds it |
| *what is it?* | the card's icon, its name and its system marks |
| *is it what the canvas shows?* | the focus wash: a subtle wash for what the canvas draws, a strong one for the pick |


## Information

| Part | Rule |
|---|---|
| **icon** | the card's, from core's `role_of`. A diagram its kind's, a plain block a plain square |
| **name** | full, cut short with an ellipsis. Hover gives the rest |
| **marks** | the card's system marks, after the name |
| **colour** | a colour edge, the same as the card's |
| **count** | quiet and right-aligned: a definition's uses, a diagram's blocks. Folders and packages carry none |
| **hover** | none: the row is already beside the tray |


## Differs from a card

| | row | card |
|---|---|---|
| shows | levels 0–1 only | up to its face |
| order | the tree's | the layout's |
| for | browsing and dragging in | reading and composing |
