# Settings

**Draft, 2026-10-29: for agreement.** The tray's card tab (a usage) and settings tab (a definition) show how an element draws: its face drawn large, and every key it says, one row each. It is the only form that shows a card's drawing as something to change.


## Purpose

| Question | How it answers |
|---|---|
| *how does it look?* | every form it takes, side by side: its card at each level (mark, head, facts, preview), then its chip as the map draws it |
| *what does it say about itself?* | every key, said or carried, one line each, cut short with an ellipsis |
| *what could it say instead?* | the lit key's choices as chips on the right |

- a definition's settings are laid out alike: each key is a part of its drawing, and the part's settings are its choices
- a usage has no settings tab: it cannot change its settings, only read them on its card tab


## Shared with the other forms

- the face is the card's own renderer, never a copy
- a chip standing for a definition wears that definition's colour
- the key rows use the identity row's type: name first, value quieter
